# Glass Dock

Glassmorphism dock and window-control layer for Windows (Tauri 2 + React). See `AGENTS.md`
for the full spec and roadmap. Current status: **Phase 0**.

```sh
pnpm install
pnpm dev:web        # interactive demo with the mock adapter
pnpm dev:desktop    # Tauri shell (Windows, needs Rust + WebView2)
pnpm lint && pnpm typecheck && pnpm test && pnpm build:web
```
